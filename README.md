# Lukmanisme Web Profile (Dual-Track POS & Studio)

Website profil personal & rekayasa sistem kasir mobile untuk UMKM karya **Lukmanisme**.

## 🚀 Fitur Utama
- **Dual-Track View:** Switcher dinamis antara Balanjo POS (SaaS Langganan) dan Sistem Kustom (Beli Lepas).
- **Interactive POS Playground:** Simulator transaksi langsung untuk Warung Makan, Laundry Datz, dan Ritel UMKM lengkap dengan animasi cetak struk thermal Bluetooth.
- **3 Studi Kasus Lapangan:** Warung Jangkung, Warung Batagor & Baso Cuangki, serta Laundry Datz.
- **Dark/Light Mode:** Editorial Tech theme dengan audio click mekanikal.
- **Direct WhatsApp Consultation:** Form konsultasi dengan prefilled template pesan.

## 🛠️ Cara Deploy ke Vercel

### Opsi A: Melalui GitHub (Rekomendasi)
1. Inisialisasi Git:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit Lukmanisme web profile"
   ```
2. Buat repository baru di [GitHub](https://github.com/new).
3. Hubungkan dan push:
   ```bash
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git branch -M main
   git push -u origin main
   ```
4. Buka [vercel.com](https://vercel.com/) $\rightarrow$ **Add New Project** $\rightarrow$ Pilih repositori GitHub Anda $\rightarrow$ Klik **Deploy**.

### Opsi B: Menggunakan Vercel CLI Langsung
Jalankan di terminal:
```bash
npx vercel
```
Ikuti instruksi login dan konfirmasi nama project. Website akan langsung aktif dalam hitungan detik!
